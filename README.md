# The Kerr Observatory

An interactive, physics-accurate simulator of the spacetime around a rotating black hole, in the style of a 1970s observatory instrument.

```sh
npm install
npm run dev      # open the printed URL in a WebGPU browser (Chrome/Edge, Safari 26+, Firefox 141+)
npm test         # physics + GPU-vs-CPU verification (headless Dawn)
npm run build
```

## What is simulated

- **Spacetime.** The exact Kerr metric in ingoing Kerr–Schild coordinates, which are regular across both horizons. Each pixel's null geodesic is integrated backwards with adaptive Dormand–Prince 5(4) in WGSL (`src/trace.wgsl`). The leftover bending to infinity is added by exact quadrature.
- **Accretion disk.** A thin Novikov–Thorne disk from the ISCO, with Page–Thorne flux. Its temperature follows from the mass and the Eddington ratio. Observed colour is the blackbody at g·T (exact), integrated against the CIE 1931 observer in absolute cd/m².
- **Sky.** 119,625 HYG catalogue stars, drawn as true point sources whose brightness follows the lensing magnification (from ray differentials). The diffuse Milky Way comes from NASA SVS Deep Star Maps with the stars removed, calibrated to Leinert et al. (1998).
- **Observer.** A real worldline with an orthonormal tetrad. It can be static, a zero-angular-momentum observer (ZAMO), on a circular geodesic, or in free fall with rocket thrust. An optional Fermi–Walker (gyroscope) frame makes the camera precess. Readouts include proper time, clock rate, proper acceleration, the tidal tensor from the Riemann curvature, and the frequency shift of starlight.
- **Display.** Pre-exposed HDR, histogram auto-exposure, bloom, the AgX display transform, and a Luminet (1979) stipple mode.

## Verification (`test/`)

The tests check:
- the 3√3 M shadow
- Bardeen's Kerr shadow edges
- capture against the Carter radial potential for random rays
- conservation of E, L and Q
- the weak-field deflection series
- disk redshift seen from the axis
- Page–Thorne against its closed form and L = (1 − E_ISCO)·Ṁ
- free fall along the cycloid through the horizon
- geodetic precession
- the Schwarzschild tidal eigenvalues and the Kerr Kretschmann invariant
- CIE illuminant A chromaticity
- camera handedness

`gpu.test.ts` renders the WGSL tracer headless and checks it against the f64 reference to within 0.01 px.

## Limits

- The GPU works in 32-bit floats.
- The disk has no colour correction, limb darkening or returning radiation.
- Sky colours are shifted along the Planckian locus of each pixel's chromaticity.
- Turbulence, bloom and sky gain are aesthetic or non-physical, and the UI labels them so.
- Free fall stops at the Cauchy horizon.

## Data

`public/` holds the data, generated by `scripts/prepare_data.py` from:
- NASA SVS Deep Star Maps 2020 (svs.gsfc.nasa.gov/4851)
- HYG v4.1
- CIE 1931 colour matching functions

`scripts/snapshot.ts` renders a plate headless to a PNG.
